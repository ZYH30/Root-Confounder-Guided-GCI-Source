# Root-Confounder-Guided Causal Effect Estimation in Complex Covariate Systems

This repository contains the code, processed data, and reproducible experiments for the paper **"Root-Confounder-Guided Causal Effect Estimation in Complex Covariate Systems"**.  The project studies causal effect estimation from observational data when the covariate system contains heterogeneous variable roles, including confounders, instruments, mediators, colliders, descendants, and outcome-side ancestors.

The proposed General Causal Inference (GCI) framework consists of two main components:

1. **Ancestor Set Identification (ASI)**, which estimates a local ancestral structure around the treatment and outcome using marginal association screening, conditional independence testing, and causal asymmetry discrimination.
2. **Root-confounder-guided adjustment**, which uses the local ancestral structure to identify upstream confounding sources and construct valid adjustment sets for downstream causal effect estimation.

The repository includes synthetic experiments, an IHDP-based semi-synthetic benchmark, NHANES analysis, Mendelian randomization validation, and supplementary adjustment-set analyses.

| `NHANESNotebook.ipynb` | NHANES local structure analysis and exploratory workflow. |
| `causalENhanesDRL.py` | Continuous-effect estimation for the NHANES triglycerides--fasting-glucose application. |

Legacy TCGA-related files are kept for completeness but are not required for the main experiments reported in the paper.

## Installation

The supplementary Python experiments use standard scientific-computing packages:

```bash
pip install -r requirements.txt
```

The full project may also require additional packages depending on which part of the repository is executed:

- Python: `numpy`, `pandas`, `scikit-learn`, `scipy`, `lightgbm`, `optuna`, `torch`
- R: packages for generalized propensity score models, NHANES data access, and Mendelian randomization
- Jupyter Notebook for the NHANES workflow

Because the original experiments combine Python, R, and notebook workflows, it is recommended to run each experimental component in the corresponding environment.

## Synthetic Data Generation

The controlled synthetic cases are defined in `DataSetup.py` and generated by `DataGene.py`.  The generated datasets are stored in:

```text
dataset/data-G-Case1.csv
dataset/data-G-Case2.csv
dataset/data-G-Case3.csv
dataset/data-G-Case4.csv
```

These four cases cover representative covariate-role patterns:

- pretreatment covariates,
- post-treatment mediators,
- post-treatment colliders,
- multiple confounding sources with collider structures.

## Ancestor Set Identification

The ASI module is implemented in:

```text
AnsFramePlus.py
utilPlus.py
```

The algorithm identifies local ancestors by combining:

1. marginal association screening,
2. conditional independence testing based on GCM,
3. causal asymmetry discrimination based on ANM,
4. recursive parent traversal for local ancestor discovery.

This local-search design is used to avoid reconstructing the complete causal graph when the scientific question concerns one treatment--outcome relation.

## Counterfactual Inference Baselines

The synthetic counterfactual inference experiments use several established continuous-treatment estimators and neural baselines:

```text
baselineModel-Ans.R
DRL-AnsF.py
DRNets-AnsF.py
```

These scripts compare causal effect estimation under different covariate inputs and report factual and marginal-treatment-effect errors.

## IHDP-Based Semi-Synthetic Benchmark

The IHDP benchmark is stored under:

```text
IHDP/
```

The benchmark starts from the real IHDP covariates and generates additional interrelated variables to create a complex covariate system with continuous treatment and outcome variables.  The corresponding scripts include data generation, ASI analysis, and downstream causal effect estimation.

## NHANES Application

The NHANES analysis focuses on the relationship between triglycerides and fasting glucose.  The main files are:

```text
dataAccess.R
NHANESNotebook.ipynb
causalENhanesDRL.py
MR_NHANES.R
```

The observational analysis estimates a triglycerides--fasting-glucose response curve after GCI-guided adjustment.  The Mendelian randomization script provides external genetic validation of the effect direction.

## Supplementary Experiments

Additional experiments are organized in:

```text
supplementary_experiments/
```

They provide reproducible analyses for:

1. adjustment-set relationships in the four controlled synthetic DAGs,
2. adjustment-set baseline comparisons on the synthetic datasets,
3. adjustment-set robustness diagnostics under multiplicative, heteroscedastic, and interaction-based mechanisms,
4. ASI discovery diagnostics under additive-reference and ANM-violating mechanisms,
5. NHANES internal-baseline diagnostics.

Run the scripts from the repository root.

### 1. Adjustment-set relationship table

```bash
python supplementary_experiments/experiments/01_make_adjustment_set_table.py
```

Outputs:

```text
supplementary_experiments/results/tables/table_adjustment_set_relationship.csv
supplementary_experiments/results/tables/table_adjustment_set_relationship.tex
```

### 2. Synthetic adjustment-set baseline comparison

```bash
python supplementary_experiments/experiments/02_run_synthetic_adjustment_baselines.py
```

Outputs:

```text
supplementary_experiments/results/tables/synthetic_adjustment_baselines_table.csv
supplementary_experiments/results/tables/table_synthetic_adjustment_baselines.tex
```

### 3. Robustness diagnostics under alternative structural mechanisms

```bash
python supplementary_experiments/experiments/03_run_noise_robustness.py --n-repeats 5 --poly-degree 3 --ridge-alpha 1.0 --save-generated-data
```

Outputs:

```text
supplementary_experiments/results/tables/noise_robustness_compact_mean.csv
supplementary_experiments/results/tables/table_noise_robustness_compact_mean.tex
supplementary_experiments/results/generated_data/
```

### 4. ASI discovery diagnostics under ANM-violating mechanisms

```bash
python supplementary_experiments/experiments/05_run_asi_non_anm_discovery_robustness.py --n-repeats 10 --n-samples 1500 --n-estimators 80
```

This diagnostic reruns the ASI-style marginal screening, residual conditional-independence testing, and directional residual testing under additive-reference, multiplicative, heteroscedastic, and interaction-based mechanisms.  Under non-ANM mechanisms, directions that are not distinguishable by the ANM residual test are retained as upstream candidates by default.

Outputs:

```text

supplementary_experiments/results/tables/table_asi_non_anm_discovery_compact.tex
supplementary_experiments/results/tables/asi_non_anm_discovery_details.csv
```

### 5. NHANES internal-baseline diagnostics

Outputs:
